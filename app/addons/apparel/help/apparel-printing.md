## Print

1. Select the pieces to print (nothing selected = every piece).
2. Type {{cmd:PATTERNPRINT}}.
3. Choose {{ui:Tiled for a home printer}} or {{ui:Full size on a plotter}}.
4. Type the sizes to print ({{key:Enter}} = every size).
5. For tiled pages, choose {{ui:A4}} or {{ui:Letter}} and the overlap between pages.

You get one PDF. Pieces print at 1:1, as true lines.

:::warning
Print at **100 %** or **actual size**. "Fit to page" shrinks the pattern. Measure the test square before you cut.
:::

## Tiled pages

Each size starts with a **cover page**: a test square (10 cm, or 4 in in a drawing in inches) and a map of the pages. Then one page per tile that has part of the pattern on it.

- Pages are named by **row letter** (from the top) and **column number**: `A1`, `A2`, `B1`. Each page names its neighbours.
- Trim each page on its outer line. The dashed lines show where the next page overlaps.
- Lay the pages out by their names, overlap them so the **diamonds** meet (each diamond is labelled with the two pages it joins, `A1|A2`), and tape.

## Full size

Each size is one page as big as the pieces, for a plotter or a print shop. A PDF page can be up to 5.08 m (200 in) long; print bigger patterns tiled or a few pieces at a time.

{{cmd:EXPORT}} offers both as {{ui:Apparel pattern, tiled pages (PDF)}} and {{ui:Apparel pattern, full size (PDF)}}, with every size.
